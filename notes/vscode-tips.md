> **샘플 노트입니다.** 아래 단축키는 VS Code 기본값(macOS) 기준입니다.
> 개인 설정이나 확장에 따라 다를 수 있으며, 사용 경험 항목은 아직 작성하지 않았습니다.

## 탐색

| 동작 | macOS | Windows / Linux |
|---|---|---|
| 파일 빠르게 열기 | `Cmd + P` | `Ctrl + P` |
| 명령 팔레트 | `Cmd + Shift + P` | `Ctrl + Shift + P` |
| 정의로 이동 | `F12` | `F12` |
| 전체 검색 | `Cmd + Shift + F` | `Ctrl + Shift + F` |
| 터미널 열기·닫기 | ``Ctrl + ` `` | ``Ctrl + ` `` |

## 편집

| 동작 | macOS | Windows / Linux |
|---|---|---|
| 다음 같은 단어 선택 추가 | `Cmd + D` | `Ctrl + D` |
| 커서 추가 | `Option + 클릭` | `Alt + 클릭` |
| 줄 위·아래로 이동 | `Option + ↑ / ↓` | `Alt + ↑ / ↓` |
| 심볼 이름 바꾸기 | `F2` | `F2` |

## 설정

- 설정 화면은 명령 팔레트에서 `Preferences: Open Settings`로 엽니다.
- 프로젝트별 설정은 `.vscode/settings.json`에 둡니다.
