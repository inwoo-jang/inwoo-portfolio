## 한 줄 정의

MCP(Model Context Protocol)는 AI 애플리케이션이 외부 데이터와 도구에 **같은 방식으로** 연결되도록 정한 개방형 프로토콜입니다.
도구마다 연동 코드를 따로 만드는 대신, MCP 서버 하나를 여러 AI 애플리케이션에서 재사용할 수 있습니다.

## 구성 요소

| 구성 요소 | 역할 |
|---|---|
| 호스트(Host) | 사용자가 쓰는 AI 애플리케이션. 하나 이상의 클라이언트를 관리 |
| 클라이언트(Client) | 호스트 안에서 서버 하나와 1:1로 연결을 유지 |
| 서버(Server) | 도구·데이터를 MCP 규격으로 제공하는 프로그램 |

메시지는 JSON-RPC 2.0 형식이며, 로컬 프로세스는 표준 입출력(stdio), 원격 서버는 HTTP 기반 전송을 씁니다.

## 서버가 제공하는 것

- **Tools** — 모델이 호출할 수 있는 함수 (예: 검색, 파일 쓰기)
- **Resources** — 모델에게 읽힐 수 있는 데이터 (예: 파일 내용, 문서)
- **Prompts** — 재사용할 수 있는 프롬프트 템플릿

## 보안에서 확인할 것

- 서버가 할 수 있는 일을 최소 권한으로 제한하기
- 도구 설명과 외부 데이터에 섞인 지시문을 그대로 믿지 않기
- 파일 쓰기·외부 전송처럼 되돌리기 어려운 도구는 사용자 확인을 거치기
