  1. 2026.09.11

    Why build an AI service? — which part of the user's work are you changing

    Being able to generate answers with AI isn't a reason to adopt it. I think we need to identify which user task to improve, consider whether it can be solved without AI, and design a flow that lets users recognize and correct errors.

    • Planning and tech choices
    • AI product planning
  2. 2026.11.06

    Comparing IDEs — VS Code · Kiro · Cursor

    VS Code is mix-and-match, Kiro is spec-driven, Cursor is agent-driven. A comparison of how each handles AI coding, project rules, and planning and verifying work, based on official docs.

    • Dev tools
    • AI coding
  3. 2026.08.28

    Does Claude Code use my personal settings when called from an app?

    Calling a CLI locally can bring personal settings and instructions into the session. I looked into how to exclude settings, disable tools, and stream the response to the screen as it is generated.

    • AI and agents
    • Claude Code
  4. 2026.07.15

    10 prompt techniques — which one to reach for, and when

    I think the desired result should guide the choice of prompt technique. I structure the request with RICE, use examples when the output format matters, and Step-back when the premise needs checking.

    • AI and agents
    • Prompt Engineering
